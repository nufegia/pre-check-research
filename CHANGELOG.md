# Changelog

## v1.1.0

- Renamed the package and documentation to `pre-check-research` with `pcr` as the CLI and output prefix.
- Added project-level audit workflows for mixed research materials, including deterministic routing, provenance checks, local corpus screening, reference metadata checks, image triage, code review/rerun notes, and cross-material data tracing.
- Expanded raw data and summary-stat checks, including digit distribution, repeated/similar rows and columns, column relationships, ordinal concentration, p-value distribution, and confidence annotations.
- Added benchmark coverage for raw tables, summary statistics, text statistics, analysis code, images, provenance, corpus screening, and optional external reference lookups.
- Prepared the repository for GitHub open-source release with MIT licensing, contribution/security guidance, and cleaned local runtime outputs.
